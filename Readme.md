Project Title
A Machine Learning Approach for Identifying Psychological Triggers in Phishing Emails to Enhance User Awareness.

Project Vision
This project aims to support general email users by improving their ability to recognise social engineering attempts. IT addresses the problem that current phishing alert systems lack psychological context, which results in low user awareness and increased vulnerability to advanced social engineering attacks. The project proposed a AI-Enhanced Phishing Awareness System in a machine-learning-based detection and explanation framework that analyses the text of emails to identify and highline psychological triggers commonly used by attackers, such as urgency, authority, and scarcity.
By providing clear, contextual feedback, the system aims to improve users’ long-term understanding and resistance to phishing attempts.
